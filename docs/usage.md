# Tree Usage

## Purpose

This document explains how to use LD-TOOLS-Tree from the command line.

Supported platforms:

- Windows
- Linux
- macOS

## Requirements

- PowerShell 7 or later
- Access to the `ld-tree.ps1` entry point

## Available commands

| Command | Description |
|---------|-------------|
| `help` | Display available commands |
| `version` | Display current version |
| `create` | Create a filesystem from a tree file |
| `export` | Export a filesystem to a tree file |
